Tizen TV principles

O Design System parte de quatro regras: legibilidade a distância, navegação por quatro direções, foco inequívoco e redução de carga cognitiva.

10-foot UI

Elementos essenciais precisam continuar legíveis a aproximadamente 3 metros. Metadados não devem competir com títulos e ações.

minimum practical body: 16px
4-way first

Todo fluxo deve ser concluído usando apenas ↑ ↓ ← →, Select e Return. Mouse e teclado são extras.

no diagonal dependency
Focus is location

Somente um item recebe foco. O usuário deve saber onde está sem precisar interpretar cores sutis.

1 focus / screen
Reduce workload

A TV é contexto de relaxamento. Agrupe informações parecidas e esconda detalhes técnicos até serem solicitados.

progressive disclosure

Regras de UX

Menos digitação, mais descoberta

O teclado existe para completar uma intenção já iniciada. Ele não deve ser a primeira experiência de busca.

1. Sugestões primeiroRecentes, tendências, gêneros e intents reduzem drasticamente o número de teclas pressionadas.
2. D-pad previsível←/→ ficam na mesma linha. ↑/↓ preservam aproximadamente a mesma coluna, evitando saltos diagonais.
3. Teclas maiores58 px de altura, foco sem escala e Espaço largo. O layout não se move quando a tecla recebe foco.
4. Voz como atalhoQuando disponível, voz aparece perto de Limpar — não escondida numa segunda tela.
5. Não usar para segredos longosURLs, tokens e credenciais continuam no Samsung IME ou pareamento por celular.
6. Return fechaReturn sai do teclado e devolve foco ao launcher/campo que o abriu. O texto digitado é preservado.

Performance budget

Em TV, memória e estabilidade têm prioridade sobre microefeitos. Imagens decodificadas e DOM extenso são os maiores custos.

DOMWindowed

Renderizar somente viewport + buffer em catálogos extensos.

ImagesDisplay-size

Thumbnail no tamanho necessário; não reduzir imagem 4K para card pequeno.

AnimationTransform/Opacity

Evitar layout thrash, filtros e camadas GPU permanentes.

LifecycleRelease

Pausar timers/mídia e liberar recursos pesados quando app fica oculto.

Não aplicar translateZ(0) ou will-change em todos os cards. Promoção de camada permanente pode aumentar o uso de GPU/memória em TV.

Accessibility & comfort

O Lab não depende de cor para foco, oferece reduced motion e evita texto crítico em microtamanho.

Reduced motion

Respeitar prefers-reduced-motion quando disponível e expor opção interna para TVs/engines que não suportam a media query.

Contrast

Texto principal permanece claro sobre superfícies escuras; foco usa borda + escala + sombra.

Labels

Ícones sem texto ganham tooltip/rótulo no foco. Não depender de símbolos ambíguos.

Audio/Subtitles

Áudio e legendas devem ser acessíveis no player sem sair do conteúdo.

Safe reading

Evitar blocos longos de texto e manter largura confortável para leitura a distância.

Privacy

Perfis deixam claro quem está ativo; credenciais BYOK nunca ficam expostas visualmente.

Do / Avoid

Regras rápidas para impedir que novos componentes tragam de volta padrões de web/mobile inadequados à TV.

Faça

  • ✓ Use grid/fila com vizinhos claros.
  • ✓ Revele detalhes sob demanda.
  • ✓ Preserve foco ao voltar.
  • ✓ Mostre feedback para operações lentas.
  • ✓ Mantenha ação principal evidente.

Evite

  • × Teclado virtual permanente na tela.
  • × Texto pequeno ou excesso de metadados.
  • × Foco apenas por mudança de cor.
  • × Hover obrigatório para descobrir ações.
  • × Milhares de cards montados no DOM.
